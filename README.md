# GRC Portfolio

Practical Governance, Risk and Compliance portfolio demonstrating applied information security governance, risk management and compliance skills.

## Portfolio projects
1. ISO/IEC 27001:2022 ISMS implementation (in progress)
2. Information security risk assessment
3. NIST Cybersecurity Framework 2.0 gap assessment
4. GRC internal audit
5. Third-party risk management
6. UK GDPR data protection impact assessment

## How to use this portfolio
Each project uses a fictional organisation and synthetic data. Deliverables are learning exercises and do not represent client work, certification, legal advice or an independent audit opinion.
