# NIST Cybersecurity Framework (CSF) 2.0 Gap Assessment

## Project Overview

This project demonstrates a simulated cybersecurity maturity and gap assessment for Northstar Digital Ltd, a fictional UK-based SaaS company with approximately 75 employees.

The assessment uses the NIST Cybersecurity Framework (CSF) 2.0 to evaluate the organisation's hypothetical cybersecurity practices, identify improvement opportunities and recommend prioritised actions.

## Organisation Profile

- **Organisation:** Northstar Digital Ltd (fictional)
- **Industry:** Software as a Service (SaaS)
- **Location:** United Kingdom
- **Employees:** Approximately 75
- **Technology environment:** Cloud-hosted customer CRM and workflow platform
- **Information handled:** Customer account details, contact information and support tickets

## Assessment Objectives

- Evaluate hypothetical cybersecurity practices against NIST CSF 2.0.
- Identify gaps across the six CSF functions.
- Assess current and target cybersecurity maturity.
- Identify risks and improvement opportunities.
- Develop a prioritised remediation roadmap.
- Present findings and recommendations in a management-friendly format.

## Framework Coverage

The assessment covers all six NIST CSF 2.0 functions:

1. Govern (GV)
2. Identify (ID)
3. Protect (PR)
4. Detect (DE)
5. Respond (RS)
6. Recover (RC)

## Project Deliverables

The project will contain:

- Assessment scope and methodology
- NIST CSF 2.0 gap assessment matrix
- Maturity scoring methodology
- Findings and improvement recommendations
- Prioritised remediation plan
- Management summary

## Important Disclaimer

This is a simulated portfolio exercise based on a fictional organisation. Assessment ratings, findings and recommendations are illustrative and are not based on actual interviews, technical testing, organisational records or independent audit work.

This project does not represent a formal NIST assessment, certification or assurance opinion.
